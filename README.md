📱 Python-to-APK: A learning project on compiling applications

Welcome to my learning repository! Here, I’m studying the process of turning simple Python applications using the Kivy framework into full‑fledged mobile applications (Android APK).

🎯 The goal of the project:

This repository is my “sandbox” and learning platform. 🛠️ What’s inside?

In this repository, you’ll find:

Simple examples of Python applications with a Kivy interface.
Configuration files (buildozer.spec) to customize the build process.
Automated build via GitHub Actions, which allows you to get a ready .apk file every time you make a code change.
Examples of errors and their solutions that will help other beginners avoid typical problems.
🚀 How does it work?
Writing code: I create simple Python programs with a graphical interface using Kivy.
Build configuration: I use the Buildozer utility to prepare all dependencies and generate the buildozer.spec specification file.
Automation: I configure GitHub Actions so that an automatic build of the Android app is triggered after each commit.
Result: In the artifacts section of each build, a ready‑to‑install .apk that can be downloaded directly from the browser.
❗ Important warning!

This is not a production project. The code here may not be the most optimal or secure, and the folder structure may be chaotic. My goal is to learn, so I will try different approaches, make mistakes, and correct them publicly.

If you’re also starting to explore this topic, join me! Watch how I solve problems, ask questions, and share your findings.
